# November 6 matcher false alarms

This source candidate builds on main `2398b05fc2f16f98a628d83a276620f0e5fb1601`. It changes how the Claude adapter's `record.py` reads the user's words and evaluates checks, so that ordinary wording and calendars no longer block a correct record. It does not change the Python engine, protocol versions, record format or tools.

## Prepared distribution identities

- The Claude adapter **0.3.9** carries the changes below in `rumbo/scripts/record.py`, with `rumbo/SPEC.md` updated to match.
- Python engine/package **0.3.5** and the OpenAI portable and Codex local adapters **0.3.6** are unchanged.
- Isolated Sites candidate **0.1.3** and its board app **0.1.3** are unchanged, as is the local board app **0.1.2**.

## What changed

- A clock time with no am/pm, an hour from 1 to 12 and no leading zero, sources both halves of the day. Before, "out by 1:00" could not source 13:00, and 01:00 failed the arithmetic, so a correct afternoon schedule always blocked.
- Numbers in words count as their value: "five hundred", "forty-five", "twelve hundred". Durations in words source minutes: "an hour", "one-hour", "two hours", "half an hour", "an hour and a half". Before, each was `UNSOURCED`.
- A `fits_window` whose `end` is earlier than its `start` ends the next day. Before, a 22:00 to 02:00 window failed as "ends 25:00".
- Two `MM-DD` dates take the closer reading, so a December 20 deadline before a January 5 event passes. A March 20 deadline for a March 12 event still fails. Dates with a year compare as written.
- "before" no longer counts as a pointer to an earlier decision, so "undo the last change before you send it" does not report `EARLIER_APPROVAL`.
- The no-record planning nudge ignores slices (`a[1:20]`), `file:line:col` positions, `HH:MM:SS` log stamps and `line N:NN`.

## Known limits

Retraction detection is still word matching. "Let's go with $800 total" with no retraction word is not detected, and "instead" plus a word shared with the item still reopens it, as `SPEC.md` describes. The planning nudge still fires on "may 2", "decide" and shell `$1`. A duration in words counts only when it is one number, so "two three-hour meetings" does not source 180 and "two and a half hours" sources nothing; quote the digits or record each meeting.

## Verification, packaging and rollback

Run the Claude-adapter suite from `rumbo/` on python3 and on Python 3.9, then the release identity checks from the repository root. One release identity test needs the `jsonschema` developer dependency.

```sh
(cd rumbo && python3 -m unittest discover -s tests)
python3 -m unittest tests.test_release_identity
```

The Claude directory reads the plugin from `rumbo/` on main. No OpenAI submission, approval or Sites deployment is claimed. To roll back, return to `2398b05fc2f16f98a628d83a276620f0e5fb1601`. There is no data migration.
