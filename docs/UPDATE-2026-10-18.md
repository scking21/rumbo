## Focus continuity

A snapshot replacing a focused Copy handoff button or clipboard-fallback textarea restores useful focus without retaining stale summary bytes or allowing an old clipboard completion to steal focus. An unchanged task returns to its current Copy control; a changed task/project returns to task navigation.

The hosted selector preserves focus when replacing task detail or task navigation. Repeated selector updates retain the same authorized project choice by exact project key, including after reordering or alias changes. A removed choice falls back to the first remaining project, or the existing empty explanation. Selecting a project moves focus to the selected visible task or its detail when no navigation item is available. Connected outside controls retain focus, including when the user moves away while a selection response is pending. Existing asynchronous request authority remains unchanged.

This does not add selector Refresh recovery, alter unsupported-host refresh behavior or change initialization retries. Those separate prior candidate bytes are unavailable and are not reconstructed by this update.
