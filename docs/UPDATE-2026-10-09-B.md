# Second October 9 update

This candidate follows [the earlier October 9 update](UPDATE-2026-10-09.md). Its update path, rollback steps and publication gates are unchanged and are not repeated here. No ledger, registry or record format changes; no dependency changes.

These are prepared distribution identities, not evidence of public release, marketplace approval or installed-host verification. Sites runtime sources are unchanged apart from the refreshed Python test oracle.

## Python engine 0.3.2

- Every refusal that used to repeat its own code now says what is current or what to do: `STALE_CONTRACT` names the current revision, `STALE_ARTIFACT` tells a missing artifact from an outdated or wrong revision, `LEASE_REQUIRED` tells a missing or expired lease from another actor's, `DEPENDENCY_BLOCKED` names the dependencies awaiting acceptance, `UNKNOWN_TASK` lists the contract's task ids. Codes are unchanged, so callers that branch on codes are unaffected.
- `state`, `call` and `mcp` no longer leave an empty `.rumbo/` in a directory that has no project, and the HTTP server no longer recreates an empty ledger when a project's database disappears after startup. Both now refuse with `NO_CONTRACT` or HTTP 503. Only the owner's `create_contract`, `demo` and server startup create storage.
- The HTTP server answers 503 JSON when a project root is removed or made inaccessible after startup, instead of dropping the connection.
- `python3 -m rumbo.registry` gains owner-run `list` and `remove`, so a project that was moved or restored can be registered again. See [the installed plugin setup](INSTALLED-PLUGIN.md).
- `python3 -m rumbo --version`; malformed `--json` is reported as `BAD_INPUT` naming its source.

## Claude adapter 0.3.4

- Quote verification: a contraction typed with a typographic apostrophe ("Don’t spend $900"), any other contraction ending in n't, `neither`, `nor`, `nobody`, `none` and `nothing` now negate, and a pause written as dots or an ellipsis no longer ends the clause a negation applies to. Curly and straight apostrophes and quotation marks match each other, so an honestly copied quote is not reported `UNVERIFIED` over typography.
- The source check accepts the ways people write dates and times: "March 20th", "20 March", "the 20th of March", "3/20", "Sept 5", "9am", "9 p.m.", "noon", "midnight", "2-hour" for 120 minutes and "$1.5k" for 1500. A bare "at 9" still sources nothing.
- Per-session marker files live in a private directory (0700, files 0600) that must belong to the current user, and are never opened through a symlink.
- `record.py` parses again on Python 3.9 to 3.11 after a syntax slip in this candidate's own development; the adapter suite runs on 3.9 in CI.
