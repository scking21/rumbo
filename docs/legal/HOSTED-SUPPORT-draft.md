# Rumbo Sites support

Draft for review · 4 October 2026

For general questions and bug reports about the Rumbo Sites candidate, use [Rumbo's GitHub issues](https://github.com/scking21/rumbo/issues).

Include the candidate version, what you expected, what happened, and reproduction steps using synthetic data. Identify the problem as affecting the Sites version so it can be distinguished from the separate local plugin.

The issue tracker is public. Do not include private project exports, actual contract text, personal information, credentials or sensitive security details. A suitable private contact for sensitive requests must be confirmed before public service launch.

Rumbo is free, and support has no guaranteed response time or fix schedule. This experimental candidate supports owner export but does not yet implement hosted restore or self-service deletion. Reporting a problem does not establish that data has been deleted or recovered.
