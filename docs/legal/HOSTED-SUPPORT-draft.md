# Rumbo Sites support

Draft for review · 4 October 2026

For general questions and bug reports about the Rumbo Sites candidate, use [Rumbo's GitHub issues](https://github.com/scking21/rumbo/issues).

Include the candidate version, what you expected, what happened, and reproduction steps using synthetic data. Identify the problem as affecting the Sites version so it can be distinguished from the separate local plugin.

The issue tracker is public. Do not include private project exports, actual contract text, personal information, credentials or sensitive security details. A suitable private contact for sensitive requests must be confirmed before public service launch.

Rumbo is free, and support has no guaranteed response time or fix schedule. The deployed owner-private runtime is v4, Sites source `c477594`, with owner export and owner-confirmed project deletion. Hosted restore is not implemented. Reporting a problem does not establish that data has been deleted or recovered.

The deletion flow requires the exact project ID and a fresh confirmation. Export before starting if you need a copy. If cleanup reports pending or is interrupted, continue through the owner browser and wait for completion before treating application-held content as deleted. Completion retains pseudonymous/linkable hash-derived guard keys indefinitely, and the same owner cannot reuse that project ID. Downloaded/client copies and provider backups/logs are outside the operation; provider copy-deletion timing is unknown. See [the draft data-handling notice](HOSTED-review-notice-draft.md).
