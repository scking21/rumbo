# Rumbo support

Draft for review · 4 October 2026

For help with Rumbo, start with the [project documentation](https://github.com/scking21/rumbo). For installation of the local OpenAI plugin, see the [setup guide](https://github.com/scking21/rumbo/blob/4270f264970b30957bc4120d63250ab4e6b74fb0/docs/INSTALLED-PLUGIN.md).

For general questions, bugs or feature requests, [open a GitHub issue](https://github.com/scking21/rumbo/issues). Include:

- Your Rumbo version and whether you use the local OpenAI plugin, Claude adapter or a hosted deployment
- Your operating system and relevant host version
- What you expected, what happened and the smallest non-sensitive steps that reproduce it
- A sanitized error message or synthetic example, when useful

GitHub issues are public. Do not upload live databases, private transcripts, credentials or confidential project files. Do not post vulnerability details that could put other users at risk; consult the repository's [security guidance](https://github.com/scking21/rumbo/blob/4270f264970b30957bc4120d63250ab4e6b74fb0/SECURITY.md) first.

Rumbo is a free project. Support has no guaranteed response time or fix schedule.
