# October 30 Stop gate reader

This source candidate builds on main `6d391edccc65bfa01a38fb3fe2c4f06591007374`. It changes what the Claude adapter's Stop gate reads as the user's words. It does not change the Python engine, protocol versions, stored data or tools.

## Prepared distribution identities

- The Claude adapter **0.3.7** carries the two reader changes below in `rumbo/scripts/record.py`, with `rumbo/SPEC.md` and the commitments skill updated to match.
- Python engine/package **0.3.5** and the OpenAI portable and Codex local adapters **0.3.6** are unchanged.
- Isolated Sites candidate **0.1.3** and its board app **0.1.3** are unchanged, as is the local board app **0.1.2**.

This patch identity distinguishes changed adapter bytes from the merged Claude 0.3.6, following [the prior update](UPDATE-2026-10-29.md).

## What changed

- Blocks the app injects no longer count as the user's words. A leading `system-reminder`, `ci-monitor-event`, `create-pr-command` or `local-command-stdout` block is removed and the rest of the message is kept, so a reminder holding a word like "instead" no longer raises a false `EARLIER_APPROVAL`. The same tags later in a message stay, so a typed example keeps its words.
- Compaction summaries and prompts a hook rewrote (`promptRewritten`) no longer count as the user's words.
- A decision made in a question dialog now counts. Each option picked, the typed `response` and each annotation's `notes` in answer to an AskUserQuestion call earlier in the same transcript is a message of its own, and the negation and retraction rules apply to it as to any other message. A dialog that resolved while the user was idle, marked by `afkTimeoutMs`, counts for nothing, and so does an answer a hook supplied, marked by `permissionDecision.source` `hook`. The labels are written by the agent, and the reader sees only what the host recorded. An unattended SDK host or a `PostToolUse` hook can supply an answer and leave no mark on the row.
- A prompt typed while the agent works now counts. Claude Code records most of these as `queued_command` attachments, not `user` entries. The reader trusts the host's `human` origin on them.

## Verification, packaging and rollback

Run the Claude-adapter suite from `rumbo/`, the release identity checks from the repository root, and a Python 3.9 compile of `rumbo/scripts/record.py`.

```sh
(cd rumbo && python3 -m unittest discover -s tests)
python3 -m unittest tests.test_release_identity
```

The Claude directory reads the plugin from `rumbo/` on main. No OpenAI submission, approval or Sites deployment is claimed. To roll back, return to `6d391edccc65bfa01a38fb3fe2c4f06591007374`. There is no data migration.
