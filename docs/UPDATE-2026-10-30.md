# October 30 Stop gate reader

This source candidate builds on main `6d391edccc65bfa01a38fb3fe2c4f06591007374`. It changes what the Claude adapter's Stop gate reads as the user's words. It does not change the Python engine, protocol versions, stored data or tools.

## Prepared distribution identities

- The Claude adapter **0.3.7** carries the two reader changes below in `rumbo/scripts/record.py`, with `rumbo/SPEC.md` and the commitments skill updated to match.
- Python engine/package **0.3.5** and the OpenAI portable and Codex local adapters **0.3.6** are unchanged.
- Isolated Sites candidate **0.1.3** and its board app **0.1.3** are unchanged, as is the local board app **0.1.2**.

This patch identity distinguishes changed adapter bytes from the merged Claude 0.3.6, following [the prior update](UPDATE-2026-10-29.md).

## What changed

- Blocks the app injects no longer count as the user's words. `system-reminder`, `ci-monitor-event`, `create-pr-command`, `task-notification`, `local-command-stdout`, `bash-stdout`, `bash-stderr` and `comment-anchor-context` blocks are removed and the rest of the message is kept, so a reminder holding a word like "instead" no longer raises a false `EARLIER_APPROVAL`.
- A decision made in a question dialog now counts. Each option picked or text typed in answer to an AskUserQuestion call earlier in the same transcript is a message of its own, and the negation and retraction rules apply to it as to any other message. The labels are written by the agent, so a verified pick shows the user chose those words, not that they wrote them.


The Claude directory reads the plugin from `rumbo/` on main. No OpenAI submission, approval or Sites deployment is claimed. To roll back, return to `6d391edccc65bfa01a38fb3fe2c4f06591007374`. There is no data migration.
